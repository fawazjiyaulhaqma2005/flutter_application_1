# Aplikasi Flutter

## Deskripsi
Aplikasi ini merupakan proyek pengembangan aplikasi mobile menggunakan Flutter dan bahasa pemrograman Dart. Aplikasi dibuat untuk memenuhi tugas perkuliahan.

## Teknologi yang Digunakan
- Flutter
- Dart
- Android Studio
- Visual Studio Code

## Fitur Aplikasi
- Menampilkan halaman utama aplikasi.
- Menampilkan daftar produk.
- Menampilkan detail produk.
- Navigasi antarhalaman.
- Menampilkan gambar produk.

## Library yang Digunakan
- provider
- go_router
- cached_network_image

## Cara Menjalankan Aplikasi

1. Clone repository ini.
2. Buka folder proyek menggunakan Visual Studio Code.
3. Buka terminal.
4. Jalankan perintah berikut:

```bash
flutter pub get
```

5. Hubungkan HP Android atau jalankan emulator.
6. Jalankan aplikasi dengan perintah:

```bash
flutter run
```
